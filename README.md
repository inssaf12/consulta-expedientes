# Consulta Expedientes - Seguimiento de Trámites
App para clientes para consultar el estado de su expediente (en trámite, resuelto, pendiente de documentación).

**Tecnologías:** Java, Android Studio, API REST, SQLite

**Funcionalidades:**
- Consulta de estado de expediente en tiempo real
- Notificaciones de cambios
- Histórico de trámites

Proyecto realizado durante prácticas FCT - DAM 2024-2026
